SAYAN BOXER - READY FOR GITHUB UPLOAD
====================================

IMPORTANT: GitHub does not automatically extract ZIP files.

1. Extract SayanBoxer_Ready_For_GitHub_Upload.zip on your Windows computer.
2. Open the extracted folder. You should immediately see:
   settings.gradle, build.gradle, gradle.properties, app/, .github/
3. Open your GitHub repository (for example Sayan_Boxer_timer).
4. Use Add file > Upload files and upload the CONTENTS of the extracted folder,
   not the outer folder and not the ZIP itself.
5. Check that 'settings.gradle' is in the TOP LEVEL (beside app/).
6. IMPORTANT: hidden .github/workflows/build-apk.yml must also be uploaded.
   If your GitHub uploader misses .github, click Add file > Create new file,
   name it '.github/workflows/build-apk.yml' and paste the contents from
   the workflow file included with this ZIP.
7. Commit changes. Open Actions > Build Sayan Boxer APK > Run workflow.
8. If the build succeeds, open the run > Artifacts > SayanBoxer-Android-APK.
   Extract that artifact ZIP and install app-debug.apk on Android.

The GitHub Actions workflow builds a DEBUG-SIGNED testing APK automatically.
An APK was NOT built or device-tested when this ZIP was created.
If any Action step is red, open it and copy the error lines for troubleshooting.
